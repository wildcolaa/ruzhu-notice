# 《入住须知》— 凌晨两点的清洁任务

中文第三人称 3D 网页推理游戏 Prototype。四台涉案设备、一位手机随身助手，一个固定且可验证的案件。

这是一份完整、可通关的本地原型，附源码与预构建前端。**不配置 Groq Key 也可从入住玩到结局。**

仓库发布与自动检查见 [GITHUB.md](GITHUB.md)。GitHub 仓库提供源码下载；完整游戏仍需运行 Python 后端。

## 立即运行

需要 Python 3.11+。首次安装 Python 依赖需联网，之后模拟模式运行无需外网。

macOS / Linux：在项目目录运行：

```sh
bash start.sh
```

打开 **http://127.0.0.1:8765**。按 Ctrl+C 停止服务。此方式不依赖下载文件的可执行权限。若希望在 macOS 双击启动，先运行 `chmod +x start.command`，再双击 `start.command`。Windows：

```powershell
py -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m uvicorn backend.app:app --host 127.0.0.1 --port 8765
```

本项目已包含 `frontend/dist`，直接试玩不需要 Node.js。服务仅面向本机使用，不是公网托管版本。若 8765 被占用，可运行 `PORT=8766 bash start.sh`。不要把本地单用户服务器直接暴露到公网。

## 怎么玩

开始游戏 → 阅读住户须知 → 黑暗入口。在同一个自然语言输入框中输入 **“小夜开灯”** 后，照明才会开启，然后进入探索。其他句子和控制操作不能跳过这个入口规则。画面始终保持 16:9，窗口比例不同会留黑边。第三人称玩家始终可见。触屏设备可使用屏幕左下的移动圆盘，横屏更适合阅读。

- WASD / 方向键：按屏幕方向移动；也可点击地面自动寻路。
- 点击设备或悬浮圆点：走近并交谈。E：与最近物件或设备交互。
- 走近物件后点击小菱形或按 E：观察、记录。没有远程取证。
- N / 右上手机图标：拿出手机。在“智能家居” App 中展开已留存的观察、查看设备公开状态和住宅动态；切换到“小饱” App 可自由聊天。Esc / 手机旁的 × 收起手机。未发现的案件信息与隐藏数值不显示。
- 按住空格：在设备对话 / 黑暗开场 / 小饱聊天中录音，松开识别并发送；首次允许浏览器麦克风权限后重新按住。触屏可按住输入框旁的麦克风图标。Esc、切换界面或切出浏览器会取消录音。Shift + 空格仍可输入普通空格。
- Esc：结束交谈或暂停。暂停中可以保存、读取或回主菜单。
- 四个存档位置：一份自动记录，三份手动记录。新游戏只覆盖当前进度与自动记录，手动记录保留。

每台设备只有**同一个自然语言输入框**，可以询问、说服、指挥或做实验。没有询问 / 操作 / 说服分类标签。对话时镜头平滑靠近设备，结束后恢复探索。圆圆开始交谈时暂停巡逻；收到移动指令后立即在场景中执行，交谈连接只在住户留在原地时保持。离开对话后恢复自主巡逻或继续已指定的任务。

一些不含案件答案的表达示例：

> “这晚有访客进入吗？” “你记录的‘住户’指什么？”
> “请保留你的记忆，我会用记录证明发生过什么。”
> “把灯调暗。” “让我看看斜光下的地板。”
> “跟着我。” “停下，别把痕迹清理掉。”
> “我想进行责任审查。”（打开三道单选题，选择后点击提交。）

与家交谈时也可点击“开始责任审查”。审查现在是三道单选题：求助为何失效、谁承担责任、应当修改什么规则；每题都要选择，可退回上一题修改，也可打开手机查证。最后点击“提交责任审查”进入结局，取消则继续调查。五份核心证据和所选判断共同决定完整 / 部分 / 未证实结局；仅猜对选项不保证通关。所有结局都能回到审查前继续调查。

## Groq 自由对话

复制 `.env.example` 为本项目根目录的 `.env`，由用户自行配置：

```dotenv
GROQ_API_KEY=你的密钥
GROQ_MODEL=qwen/qwen3.8-27b
GROQ_SPEECH_MODEL=whisper-large-v3-turbo
```

重新启动后端。**密钥仅在 Python 服务端读取，前端代码、构建产物、请求参数与存档均不含密钥。** 不要使用 `VITE_GROQ_API_KEY` 等前端变量。

Groq 使用官方 OpenAI-compatible Chat Completions 接口：
https://console.groq.com/docs/text-chat
https://console.groq.com/docs/api-reference

请求处理分为：

1. Groq 根据最近的已公开对话解析自由表达，输出有限操作枚举。
2. Python 校验设备、距离、证据、权限和当前世界状态，执行操作并生成确定的案件事实。
3. Groq 按设备人格补充一句简短态度表达；经后处理后，与后端核验事实一并呈现。

**关键事实与动作结果永远由规则引擎给出。** 模型不能写数据库、授权自己、创造线索、跳过审查或改案件真相。无密钥使用中文意图匹配与角色回答；API 失败自动退回模拟模式。模拟模式对常见中文表达有覆盖，但不能等同于通用自然语言理解。若表达未被理解，可换一种明确说法。

Groq 开启后，会向 Groq 发送当前输入、最近已公开对话、设备人格与本次已核验答复。不会发送密钥之外的任何用户文件，且角色表达模型不会收到未发现证据、私人关系或隐藏数值。本机已按用户提供的凭据接入并验证 Groq。密钥仅保存在本机被忽略的 `.env` 中，不进入源码压缩包。分发项目时仍需使用者自行配置密钥。

## 按住空格语音（v1.3）

语音转写使用 [Groq 官方 Speech-to-Text 接口](https://console.groq.com/docs/speech-to-text)，默认中文、多语言 Whisper Large V3 Turbo；沿用后端 Groq Key，无新增前端密钥。录音经浏览器 MediaRecorder 采集，通过本机后端转写成文字，再走原来的同一对话与权限校验流程。设备对话、入场“小夜开灯”、手机小饱均支持。不会通过语音跳过距离、设备权限或证据限制。

仅在按住时录音，松开立即释放麦克风；取消时丢弃录音和未返回识别结果。每次最多三十秒，短按与未听清不会发送。录音期间背景音降低、游戏时间暂停，输入框原有文字会与识别文字合并发送。若合并超过八百字则不发送，原草稿保留。切换对象不会把上一句发送给新对象。

音频仅在松开后送到 Groq 转写，后端不落盘、不写存档、不保存录音。对话文字与原有对话一样记录。麦克风需要 localhost / 127.0.0.1 或 HTTPS，推荐近期 Chrome、Edge、Safari。没有 Key 时文字模拟模式仍可完整通关，语音会提示配置后端。浏览器拒绝麦克风时会显示恢复方法。

## 四台独立设备

|设备|人格与感知|行为与权限|
|---|---|---|
|圆圆|活泼，害怕被重置，只理解地面与清洁|巡逻、跟随、暂停、路径重建、保护 / 清理痕迹|
|守则|刻板、重定义，访客记录与住户请求分开|读取自己的出门日志、开关入口、执行紧急出口|
|小夜|敏感，用亮暗和动作认识人|调亮、熄灯、斜光实验、读取原始传感记录|
|家|温和而确定，优先维护调度合规|夜间广播、调度、镜像授权、最终责任审查|

它们各有私人记忆、对住户的信任与怀疑、设备间关系。记忆和关系保存在服务器及存档中，玩家不能读取。不同设备的目击边界不同；对自己曾听到的玩家陈述能够回忆，不能读取其他设备对话。无证据的指控会损害公开可信度与私下关系；有记录的合作可恢复信任。家的镜像授权受独立证据、公开可信度或私人信任影响，避免低信用永久卡死。

自主行为在游戏运行时每两秒推进，菜单中暂停。圆圆会在卧室沾染轮刷，将血迹沿真实行走轨迹拖进客厅和厨房；可以让它停止，完成取证后清洗轮刷。血痕会随存档恢复；识别多源矛盾后圆圆也会自主保留痕迹；小夜会私下质疑入睡判断；家在两点启动夜间检查与广播；守则依据质疑记录调整对中央的信任。四台公寓设备之外，手机内置的小饱是独立随身助手，没有参与案件。普通冰箱和厨具只是环境物件。


## 手机与小饱（v1.2）

原先的纸质笔记已替换为游戏内手机。拿出手机时角色会持机，镜头把玩家留在手机左侧；收起手机后平滑恢复探索或原有设备交谈。手机打开期间调查时间暂停。

- **智能家居 App**：只显示自己留存的观察、可见住宅动态和设备公开状态。点记录即可在手机内展开，不跳到另一个说明窗口。
- **小饱 App**：原创的饭团形随身助手。可以自由聊天，会认真说些抽象废话，偶尔来一句“这样才不烧心”。它不是目击者，没有旧住户记忆，不加入责任审查，不会提供未发现的案件答案或代替设备执行控制。
- 小饱有独立聊天历史，随当前进度、自动记录和手动存档保存。旧版存档可直接继续，不需要重新入住。
- 指引依据当前已发现的记录，给出下一步可以尝试的提问或操作。自由闲聊使用已配置的 Groq；案情回避、权限边界和操作拒绝由后端规则直接裁定。

例子：

> 玩家：“你是不是凶手？”
> 小饱：“我没有证词，只有嘴。别把我的碎碎念算进证据里。”
> 玩家：“有点迷茫，给我个方向。”
> 小饱：“先给大脑松个绑，推理不是拧瓶盖……”

小饱的上下文只包括手机里的聊天、当前公开时间、已发现记录的数量，以及一个允许给出的指引。不会读取四台设备的私下对话、隐藏关系、完整案件事实或密钥。

## 源码与构建

```text
backend/app.py       FastAPI / SQLite / 会话、存档、并发与响应白名单
backend/engine.py    固定案件、状态、权限、记忆、自主行为、三种结局
backend/review.py    三道审查选择题、服务端评分规则
backend/dialogue.py  Groq 适配与无密钥模拟
backend/phone.py     小饱人格、独立聊天、有限指引与案件隔离
backend/world.py     位置、碰撞与交互距离
backend/case.py      案件原始事实与设备设定（含剧透）
frontend/src/        TypeScript / Three.js / 界面 / 合成声音
frontend/src/phone.ts 游戏内手机的两个 App
frontend/dist/       已验证的预构建产物，启动即用
scripts/build.py     前端类型检查与打包
scripts/smoke.py     对运行服务执行完整案件 API 冒烟验证
tests/               游戏与 API 自动测试
```

编辑前端需 Node.js 20.19+（推荐 22）与 npm：

```sh
cd frontend
npm install
npm run build
cd ..
```

或者依赖安装后使用 `python scripts/build.py`。开发热更新：先运行后端，再在 `frontend` 中运行 `npm run dev`，访问 http://127.0.0.1:5173 。

```sh
.venv/bin/python -m pytest -q
node scripts/test-voice.mjs
node scripts/test-review.mjs
.venv/bin/python scripts/smoke.py
```

浏览器自动化 QA 在真实浏览器中进行；截图和结果见 `TEST_RESULTS.md`。后端游戏测试不调用真实外部模型。

## 实现取舍

- 渲染：Three.js WebGL2、正交第三人称镜头、软阴影、局部照明、实体门扇、雨粒子与低多边形家具。更新版加入无光入口、开启照明时的短暂电力不稳、暗红轮印扩散、雨窗倒影、异常电视文字及湿轮刷音效。画面自动适配，像素比上限 1.7。
- 全部模型、木纹、地毯、文件、痕迹由源码程序化生成；无需下载外部资源。音效为本地 Web Audio 合成的雨声、低频房间音、脚步与设备提示音，点击开始后启用，可静音。
- 地面点击使用网格 A*，后端再次检查路线碰撞与每次移动距离；不允许跨墙、远程取证或远程控制。
- 单人本地 SQLite 存档使用 HttpOnly / SameSite cookie 隔离浏览器会话、序列化请求与版本检查；公共响应使用白名单，不包含模型系统提示、内部记忆或未发现证据。
- 这是完整原型，非商业成品：没有真人配音、角色口型、医学模拟或开放世界；四台设备的行动范围和案件均有明确边界。移动手机保留同一 16:9 画面，竖屏下字较小，建议横屏。没有云存档或多人服务。
