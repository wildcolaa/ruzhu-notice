# 《住进来的第三天》2.5D 网页原型

按《剧情与 AI 程序规格》做的单页可玩原型：第三人称 2.5D 正交俯视、八个房间、十一台家电 AI、三天十四节拍、五个结局。

## 怎么玩

用浏览器打开 `index.html`。不需要后端、也不需要 API Key。

- WASD / 方向键按屏幕方向移动，也可以点击地面。E 和身边的物件或家电互动。
- 每台家电只有**一个输入框**：问、说服、指挥、做实验都可以。对话时**按住空格说话，松开发送**（浏览器语音识别，需允许麦克风；Chrome / Edge 支持最好）。Shift+空格输入普通空格。
- 滚轮缩放。N 打开手机（已导出的原始记录 + 住宅动态 + 小饱）。
- 无模型时用规则对白，同样可以通关。
- **和家电自由对话（免费）**：AI 通过 `relay/` 里的 Cloudflare Worker 中转接入 Groq，Groq Key 只存在 Worker 后台，网页和仓库里都没有。部署步骤见 [relay/README.md](relay/README.md)，部署后把地址填到 `fable/src/npc.js` 的 `RELAY_URL`。玩家也可以在「AI 设置」里填自己的免费 Key（只存在本机浏览器）。AI 负责理解玩家的说法、用设备口吻回答；开门、导出记录、结局等**结果仍由规则引擎决定**，AI 不可用或超额时自动回落到规则对白。

## 源码

`fable/src/` 为拆分后的源码。改完后：

```sh
python3 fable/build.py
```

会重新生成 `index.html`（以及上级目录的 `fable.html`）。`fable/models/` 是压缩后的 GLB；不要提交 `models_raw/`。

## 规格对应

| 规格 | 本原型 |
| --- | --- |
| 八个区域 | 玄关 / 客厅 / 厨房 / 卧室 / 浴室 / 阳台 / 储物间 / 楼下设备间 |
| 十一台设备 | 小灯、门锁、扫地机、空调、音箱、冰箱、电视、浴室镜面、浇水器、住家、小饱 |
| 六份记录互证 | 门锁、小灯、扫地机、镜面、冰箱、音箱；≥2 份可让电视播放原始时间线 |
| 终夜电力 | 3 格，开门 / 旧广播 / 延缓整理互斥 |
| 五个结局 | 整理完成 / 被允许留下 / 门外 / 最后的证人 / 第三天以后 |
| 无模型试玩 | 规则意图识别 + 规则对白，可走完全流程 |
